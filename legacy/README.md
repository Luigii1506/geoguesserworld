# Legacy

Vistas y datos de la primera versión de GeoMastery (fichas escritas a mano, Atlas,
Laboratorio, Ruta, Mundo, Práctica, Repaso y los importadores antiguos). Se
sustituyeron por la app que lee la base de conocimiento del pipeline.

No se compila (tsconfig solo incluye `src/`). Se conserva porque el proyecto aún no
tiene commits; cuando la versión nueva esté validada, esta carpeta se puede borrar.
